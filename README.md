# Corbie UI

The UI is part of [Corbie](https://github.com/zummed/corbie). `corbie ui` runs it, and no program `corbie-ui` is needed.

Its code is in Corbie's repository under `ui/`, with this repository's history, and its specs are under `specs/ui/`.
